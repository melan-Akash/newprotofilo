# Melan Akash - Portfolio

Personal portfolio website for **Melan Akash**, Associate Software Engineer based in Matara, Sri Lanka. Built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Modern & Responsive UI**: Sleek dark/light mode with custom aesthetics and smooth scrolling.
- **Tech Stack Highlights**: MERN, PERN, Spring Boot, .NET, Tailwind CSS, Vite.
- **Project Showcase**: Full-stack and AI-integrated applications with live links and GitHub repositories.
- **Interactive Experience**: Smooth navigation, contact form, and social media integration.

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/melan-Akash/newprotofilo.git
   cd newprotofilo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
